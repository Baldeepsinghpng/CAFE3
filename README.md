# Demo 3: Maison Eclat Patisserie (Luxury Dessert Cafe)

Elegant, editorial, ivory and plum. **Fictional demo brand. Every detail is a placeholder.**

## Preview
Double-click `index.html`.

## Change the basics
- **Name, phone, WhatsApp, map, minimum order lead time:** `CONFIG` block at the top of `script.js`.
- **Signature cakes, prices, menu list:** `index.html`.
- **Colours:** variables at the top of `style.css`.
- **Photos:** search `index.html` for `images.unsplash.com`.

## Custom cake inquiry form
It validates name, phone, date (respecting `minLeadDays`), size and description, then shows a message saying it is a demo. **It does not send anything.**
To receive real inquiries you need one of: a form service (Formspree, Getform, Web3Forms, etc.), an email-sending backend, or a WhatsApp link that pre-fills the details. This requires the owner's consent and an account you set up.
